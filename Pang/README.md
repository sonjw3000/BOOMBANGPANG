# Universe Logistics

> 달에 건설된 복합 물류 허브를 운영하고, 화물 흐름의 병목을 찾아 안정화하는 물류 경영 시뮬레이션입니다.

## 게임 소개

인류가 태양계로 진출하기 시작한 근미래, 외딴 우주 정착지는 불안정한 장거리 보급망에 의존하고 있습니다.

플레이어는 달의 물류 허브 운영자가 되어 도착한 화물을 보관하고, 주문에 맞춰 피킹·포장한 뒤 다른 정착지로 출고합니다. 보관, 포장, 발사를 담당하는 여러 건물을 연결하고 작업자와 운영 정책을 조정하여 점점 복잡해지는 물류 흐름을 안정화해야 합니다.

Universe Logistics는 완벽한 자동 운영보다 플레이어가 흐름을 관찰하고 문제의 원인을 찾아 개선하는 경험을 지향합니다. 혼잡, 긴 이동 거리, 처리량 부족과 불안정한 운영은 제거해야 할 잡음이 아니라 플레이어가 해결해야 할 핵심 과제입니다.

## 핵심 게임플레이

```text
입고 → 보관 → 주문 → 피킹 → 포장 → 출고 → 정산
```

- **병목 중심의 물류 운영** — 작업자 동선, 시설 배치, 대기 화물과 처리량을 관찰하고 흐름을 개선합니다.
- **복수 건물 물류 허브** — Storage, Packing, Launch Building을 배치하고 Cargo Port를 통해 연결합니다.
- **눈에 보이는 작업 흐름** — 인간과 로봇 작업자가 실제 공간을 이동하며 운반, 피킹, 포장 작업을 수행합니다.
- **계약과 운영 성장** — 계약을 수락하고 납기 내 주문을 완료하여 수익과 평판을 확보합니다.
- **연구와 라이선스** — 연구로 새로운 운영 수단을 확보하고, 시설과 운영 상태를 갖춰 더 높은 물류 역량을 증명합니다.
- **온도와 화물 상태** — 냉각 성능과 전력 상태가 화물 온도와 신선도에 영향을 주며, 부적절한 보관은 폐기물과 운영 손실로 이어집니다.
- **우주 물류의 위험** — 착륙 실패, 작업자 사고와 시설 손상이 물류 흐름에 새로운 문제를 만듭니다.

## 데모 진행

현재 데모는 기본 물류 운영에서 시작해 연구와 콜드체인 운영으로 확장되는 단계별 목표를 제공합니다.

1. 첫 주문을 완료합니다.
2. 주문 3건을 납기 내 완료하여 출고 흐름을 안정화합니다.
3. 온도 모니터링과 열 운영 기술을 연구합니다.
4. 교통 제어와 인간 인식 기술을 연구합니다.
5. Lunar Produce Cold Chain 주문을 납기 내 완료하고 평판 50을 달성합니다.

## 개발 현황

현재 플레이 가능한 데모를 개발하고 있습니다.

구현된 주요 기반:

- 입고, 보관, 피킹, 포장, 출고와 주문 정산
- Storage, Packing, Staging, Launch Building
- Cargo Port와 건물 간 화물 전달
- 인간·로봇 작업자, 작업 배정, 피로와 배터리
- 계약, 주문, 경제와 평판
- 연구, 회사 상태 평가와 라이선스
- 전력, 온도, 화물 신선도와 손상
- 사고, 착륙 실패와 시설 피해
- 시나리오 목표 및 저장·불러오기

현재는 다음 항목을 중심으로 통합 완성도를 높이고 있습니다.

- 입고부터 정산까지 전체 물류 흐름의 안정화
- 건물 간 화물 전달과 Launch 출고 흐름 검증
- 데모 목표 전체의 연속 플레이 검증
- 콜드체인 연구, 시설 운영, 화물 상태와 계약 진행의 연결
- 플레이어가 병목과 실패 원인을 이해할 수 있는 운영 정보 개선

> 프로젝트는 개발 중이며 게임 규칙, 콘텐츠와 UI는 변경될 수 있습니다.

## 실행 방법

### 요구 사항

- Unity `6000.5.3f1`
- Git

### 프로젝트 열기

1. 저장소를 복제합니다.
2. Unity Hub에서 저장소 루트를 프로젝트로 추가합니다.
3. Unity `6000.5.3f1`로 프로젝트를 엽니다.
4. `Assets/Scenes/TitleScene.unity`를 열고 Play Mode를 시작합니다.
